# cmux ワークスペースの標準レイアウト（リーダー＋成果物の最大2列）

claude-teams 運用時のワークスペースは**左＝リーダー／右＝成果物の最大2列**で構成する（2026-08-07 改定＝[[Decisions/2026-08-07-teammate-in-process-permanent]]）:

| 列 | 用途 |
|---|---|
| 左 | オーケストレーター（リーダーの claude 端末） |
| 右 | 成果物表示（`show-review.sh` が開く markdown プレビュー／ブラウザ。タブで束ねる） |

- ワーカーの通常の起動・報告は [[Preferences/worker-role-prompts]]「起動形態の既定」に従う。名前付きチームメイトの表示・起動設定は、同節の例外を明示的に使うときだけ参照する。
- **初期状態はリーダー1ペインのみ**。成果物を見せるときだけ右列を増やす。2列を超える列は作らない。
- **幅は cmux の素の分割比率に任せる**（カスタム幅矯正はしない）: リーダーのみ 100% → 成果物表示で 50/50。手動リサイズも自由（何も戻さない）。
- **三段の体制の案件画面**＝マックリーダーは既存の窓口のワークスペースを使う。新規案件では親の起動前に案件ワークスペースを用意し、ノートの存在確認後にその画面を対象に案件宣言する。左は準備中の案件、親の起動後は親の非対話実行の進み具合・ログと最新報告を表示する（対話入力欄としては使わない）。本人向け資料を親・子が自分の画面へ表示しない。親・子は資料のパスと確認点をマックリーダーへ返し、マックリーダーが自分の画面の隣に表示する（提示の正本＝[[Preferences/core-conduct]]・[[Decisions/2026-11-03-show-via-mac-leader]]）。ワーカーごとのペインは増やさない。画面が閉じても処理の終了とせず、表示だけを復旧する。同じ親を対話画面と背景処理の両方で再開しない（[[Decisions/2026-11-03-three-tier-team-stage1]]）。
- **全案件の一覧の表示**＝既存の端末で、単発表示・継続更新をオプションで選び、継続時の間隔も指定できる入口を使う。継続表示は同じ端末内で記録を読み直し、親の生存・終了も毎回観測して更新する。全案件の専用画面・ワーカーごとのペイン・常駐収集は作らない。案件画面が閉じても一覧から案件や親を消さない。本人への説明と資料表示はマックリーダーが行う（[[Decisions/2026-11-03-three-tier-team-stage4]]）。
- 成果物列の配置は実行時に `~` 展開される dotfiles 内 `cmux/show-review.sh` が担当（表示ルール本体＝[[Preferences/coding-delegation]]「ユーザーへの提示」節。Vault 内ノートは表示対象外）。

## deprecated 2026-08-07（旧3列標準・チームメイト中央列）
- 旧構成＝左リーダー／中央チームメイト縦積み／右成果物の最大3列（[[Decisions/2026-07-05-cmux-3column-layout]]）。中央列は in-process 恒久化で消滅。
- ペイン運用時代の実測知見（spawn 時の自動リサイズ・右列自動縦積みの正体）は [[Knowledge/cmux-cli]] に保全。
